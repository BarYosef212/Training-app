# יומן אימונים 🏋️

אפליקציית ווב (PWA) למעקב אחרי התקדמות ותוכנית תרגילים — מותקנת על האייפון דרך ספארי, בלי App Store.

## מה יש באפליקציה
- **⚖️ שקילה** — משקל, אחוז שומן (לא חובה), הערות, גרף מגמה, שינוי שבועי/כולל, ממוצע 7 ימים.
- **📏 היקפים** — חזה, מותניים, בטן, אגן, זרוע, ירך, שוק, כתפיים, צוואר. גרף לכל מדד והשוואה למדידה הקודמת.
- **📸 תמונות התקדמות** — העלאה/צילום, תאריך ותנוחה (חזית/צד/גב), השוואה בין 2 תמונות.
- **🤖 סקירת AI** — בוחרים 1–4 תמונות, והמודל של OpenAI מנתח אותן יחד עם נתוני המשקל, ההיקפים והתרגילים ונותן סקירה והמלצות בעברית. הסקירות נשמרות.
- **🏋️ התרגילים שלי** — רשימת התרגילים שאתה עושה. לכל תרגיל:
  - סטים — משקל וחזרות לכל סט (אפשר גם טווח `8-12` או זמן `45s`)
  - קבוצת שריר ושיוך לאימון (A / B / רגליים...) עם סינון לפי אימון
  - מנוחה בין סטים, הערות, קישור לסרטון
  - היסטוריית שינויים: כשמעדכנים משקל/חזרות, הגרסה הקודמת נשמרת ומוצג גרף התקדמות
- **💾 גיבוי** — ייצוא/ייבוא של כל הנתונים (כולל תמונות) לקובץ JSON.

כל הנתונים נשמרים **מקומית במכשיר** (IndexedDB). אין שרת ואין חשבון.

## התקנה על האייפון
1. בריפו ב-GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. בכל push ה-workflow `.github/workflows/pages.yml` מפרסם את האתר אל:
   `https://baryosef212.github.io/Training-app/`
3. פותחים את הכתובת ב-**Safari** באייפון → כפתור שיתוף → **"הוסף למסך הבית"**.

## סקירת AI — מפתח OpenAI
1. יוצרים מפתח ב-[platform.openai.com](https://platform.openai.com/api-keys) (תשלום לפי שימוש, צריך יתרה בחשבון).
2. באפליקציה: ⚙︎ הגדרות → מדביקים את המפתח → שמירה.
3. מודל ברירת מחדל: `gpt-5.5`. אפשר לשנות בהגדרות לכל מודל עם תמיכה בתמונות שזמין בחשבון שלך.

המפתח נשמר רק בדפדפן שלך ונשלח ישירות ל-`api.openai.com`. אל תשתף את האפליקציה המותקנת שלך עם אחרים כשהמפתח שמור בה.
מומלץ למלא גם את הפרופיל (גובה, גיל, מטרה) כדי שהסקירה תהיה מדויקת יותר.

## מבנה הקוד
אין שלב build — קבצים סטטיים בלבד.
```
index.html                 מעטפת האפליקציה
css/styles.css             עיצוב (RTL, מצב כהה)
js/app.js                  מסכים ולוגיקה
js/db.js                   שמירה ב-IndexedDB + גיבוי
js/ai.js                   סקירת AI דרך OpenAI API
js/vendor/openai-sdk.js    ה-SDK הרשמי של OpenAI (openai 7.57.0, באנדל ESM)
sw.js                      Service Worker לעבודה אופליין
manifest.webmanifest       הגדרות PWA
```

הרצה מקומית: `python3 -m http.server 8000` ואז `http://localhost:8000`.

עדכון ה-SDK:
```bash
npm i openai esbuild
echo "export { default } from 'openai';" > entry.js
npx esbuild entry.js --bundle --format=esm --platform=browser --minify --outfile=js/vendor/openai-sdk.js
```
אחרי שינוי בקבצים כדאי להעלות את `VERSION` ב-`sw.js`.
