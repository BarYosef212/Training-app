# יומן אימונים 🏋️

אפליקציית ווב (PWA) לתיעוד אימונים והתקדמות — מותקנת על האייפון דרך ספארי, בלי App Store.

## מה יש באפליקציה
- **⚖️ שקילה** — משקל, אחוז שומן (לא חובה), הערות, גרף מגמה, שינוי שבועי/כולל, ממוצע 7 ימים.
- **📏 היקפים** — חזה, מותניים, בטן, אגן, זרוע, ירך, שוק, כתפיים, צוואר. גרף לכל מדד והשוואה למדידה הקודמת.
- **📸 תמונות התקדמות** — העלאה/צילום, תאריך ותנוחה (חזית/צד/גב), השוואה בין 2 תמונות.
- **🤖 סקירת AI** — בוחרים 1–4 תמונות, ו-Claude מנתח אותן יחד עם נתוני המשקל, ההיקפים והאימונים ונותן סקירה והמלצות בעברית. הסקירות נשמרות.
- **🏋️ אימונים** — אימון עם תרגילים, סטים (משקל × חזרות), הערות לכל תרגיל והערות כלליות. מציג מה עשית בפעם הקודמת ושיא אישי, מאפשר להתחיל מאימון קודם, ושומר טיוטה אוטומטית.
- **📚 התרגילים שלי** — ספריית תרגילים עם קבוצת שריר, הערות טכניקה וגרף התקדמות (1RM משוער).
- **💾 גיבוי** — ייצוא/ייבוא של כל הנתונים (כולל תמונות) לקובץ JSON.

כל הנתונים נשמרים **מקומית במכשיר** (IndexedDB). אין שרת ואין חשבון.

## התקנה על האייפון
1. בריפו ב-GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. בכל push ה-workflow `.github/workflows/pages.yml` מפרסם את האתר אל:
   `https://baryosef212.github.io/Training-app/`
3. פותחים את הכתובת ב-**Safari** באייפון → כפתור שיתוף → **"הוסף למסך הבית"**.

## סקירת AI — מפתח API
הסקירה משתמשת ב-Claude API (`claude-opus-5-5`).
1. יוצרים מפתח ב-[console.anthropic.com](https://console.anthropic.com) (תשלום לפי שימוש).
2. באפליקציה: ⚙︎ הגדרות → מדביקים את המפתח → שמירה.

המפתח נשמר רק בדפדפן שלך ונשלח ישירות ל-`api.anthropic.com`. אל תשתף את האפליקציה המותקנת שלך עם אחרים כשהמפתח שמור בה.
מומלץ למלא גם את הפרופיל (גובה, גיל, מטרה) כדי שהסקירה תהיה מדויקת יותר.

## מבנה הקוד
אין שלב build — קבצים סטטיים בלבד.
```
index.html              מעטפת האפליקציה
css/styles.css          עיצוב (RTL, מצב כהה)
js/app.js               מסכים ולוגיקה
js/db.js                שמירה ב-IndexedDB + גיבוי
js/ai.js                סקירת AI דרך Claude API
js/vendor/anthropic-sdk.js   ה-SDK הרשמי של Anthropic (‎@anthropic-ai/sdk 1.9.0, באנדל ESM)
sw.js                   Service Worker לעבודה אופליין
manifest.webmanifest    הגדרות PWA
```

הרצה מקומית: `python3 -m http.server 8000` ואז `http://localhost:8000`.

עדכון ה-SDK:
```bash
npm i @anthropic-ai/sdk esbuild
echo "export { default } from '@anthropic-ai/sdk';" > entry.js
npx esbuild entry.js --bundle --format=esm --platform=browser --minify --outfile=js/vendor/anthropic-sdk.js
```
אחרי שינוי בקבצים כדאי להעלות את `VERSION` ב-`sw.js`.
